# Brand Guide

## Primary Brand Colors

| Brand Role | Color | Hex Code | Use |
|---|---|---:|---|
| Primary Background | White | `#FFFFFF` | Main backgrounds, portfolio pages, case study layouts, document space |
| Accent Color | Tennessee Orange | `#FF8200` | Headings, dividers, workflow nodes, callouts, key metrics, emphasis text |
| Font Color | Black | `#000000` | Main text, section headers, labels, table content |

## Visual Identity

This portfolio uses a clean healthcare operations style with strong contrast, structured spacing, and a professional analyst-focused layout.

## Design Rules

- Use white as the dominant background color.
- Use black for all main body text.
- Use Tennessee Orange only for emphasis, not full-page decoration.
- Keep layouts clean, structured, and easy to scan.
- Use tables and workflow maps to communicate operational thinking.
- Prioritize readability over decoration.

## Recommended Visual Style

- High-contrast editorial headlines
- Clean sans-serif supporting text
- White background with intentional whitespace
- Tennessee Orange section dividers
- Workflow nodes and process maps using orange accents
- Black text for professional readability

## Portfolio Design Goal

The visual system should communicate healthcare operations clarity, revenue cycle discipline, and analyst-level workflow thinking.
